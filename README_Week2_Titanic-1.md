# Week 2 – Data Visualization and Insight Communication using R

## Project
Titanic Passenger Survival Analysis using R and ggplot2.

## Objective
Create multiple visualizations and communicate insights from a public Titanic passenger dataset.

## Tools
- R / RStudio
- ggplot2
- dplyr
- tidyr

## Dataset
Titanic passenger dataset with 891 records.

## Visualizations
1. Survival rate by sex
2. Survival rate by passenger class
3. Passenger age histogram
4. Age vs fare scatter plot
5. Survival rate across age groups
6. Fare distribution by class
7. Survival rate by sex and class
8. Survival rate by embarkation port

## Main Findings
- Overall survival rate: 38.4%
- Female survival: 74.2%
- Male survival: 18.9%
- 1st-class survival: 63.0%
- 2nd-class survival: 47.3%
- 3rd-class survival: 24.2%
